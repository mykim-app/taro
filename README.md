# 타로 상담

주제를 하나 고르고 카드 6장을 뽑아 보는 타로 상담 사이트입니다.
결과는 A4 한 장 PDF로 저장할 수 있습니다.

- 파일은 `index.html` 하나로 되어 있습니다. (카드 그림과 PDF 도구가 모두 안에 들어 있습니다.)
- 별도 서버나 데이터베이스가 필요 없고, 입력한 이름은 저장되지 않습니다.
- 카드 도판: 라이더-웨이트-스미스 타로(1909, 퍼블릭 도메인)

## GitHub Pages로 게시하는 방법 (웹 화면에서)

1. GitHub에서 `New repository`로 새 저장소를 만듭니다. (이름 예: `tarot`, Public)
2. 저장소 화면에서 `Add file` → `Upload files`를 눌러 `index.html`과 `README.md`를 끌어다 놓고 `Commit changes`를 누릅니다.
3. `Settings` → `Pages`에서 `Branch`를 `main`, 폴더를 `/ (root)`로 고르고 `Save`를 누릅니다.
4. 1~2분 뒤 `https://계정이름.github.io/tarot/` 주소로 접속됩니다.
